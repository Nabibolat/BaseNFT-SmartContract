# BaseNFT-SmartContract

A smart contract for creating and deploying an NFT collection (ERC-721 standard) on the **Base** network.

## 🚀 Project Overview
This contract is written in Solidity using secure and up-to-date **OpenZeppelin (v5.x)** libraries. It features safe minting capabilities and access control management via `Ownable`.

* **Network:** Base Mainnet
* **Standard:** ERC-721
* **Development Tools:** Remix IDE, MetaMask

## 📂 Repository Structure
* `MyBaseNFT.sol` — The original smart contract source code with external library imports.
* `MyBaseNFT_flattened.sol` — The combined (flattened) single-file source code used for successful verification on Basescan.

## 🛠️ Features
* **ERC-721 Compliant:** Fully compatible with major NFT marketplaces like OpenSea.
* **Auto-Incrementing IDs:** Secure token ID tracking for hassle-free minting.
* **Verified Source Code:** Publicly open and completely readable on the block explorer.
